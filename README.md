# 地址备忘录 · 手机网页演示

入口：https://masher-pp.github.io/address-memo-demo/

版本：2026-11-04 H5 用户端完善。搜索企业、记录位置、到访图文指引、真实厂区导航、逐站走访及本机备份。

初始含三家苏州企业、四个官网公开厂区定位，实际入口待核实；其他初始企业为演示样例。来源保留在场所资料中。

记录仅在当前浏览器 localStorage，没有登录、多人共享或服务器存储。清理网站数据会删除记录；可在设置导出 JSON。未提供导入备份。

地图采用本地 Leaflet 1.9.4 和在线 OpenStreetMap 瓦片，显示需要网络；底图不可达时可回列表，GPS 和文字记录仍可使用。Leaflet 许可见 vendor/leaflet-1.9.4/LICENSE。

导航前请安装相应地图 App，在手机浏览器打开 HTTPS 链接并允许定位。微信可能拦截外部 App。厂区坐标不是实测门岗；浏览器模拟测试不代表实体手机 App 已开始导航。
