# 地址备忘录 · 手机网页演示

入口：https://masher-pp.github.io/address-memo-demo/

版本：2026-11-11 走访选择与操作流程修正。搜索企业、记录位置、到访图文指引、厂区导航、逐站走访及本机备份。

初始含三家苏州企业、四个官网公开厂区定位，实际入口待核实；其他初始企业为演示样例。定位依据保留在 factory-data.js，不在产品界面展示。

记录仅在当前浏览器 localStorage，没有登录、多人共享或服务器存储。清理网站数据会删除记录；可在设置导出 JSON。未提供导入备份。

地图采用本地 Leaflet 1.9.4 和在线 OpenStreetMap 瓦片，失败时自动切换 Esri 街道底图；显示需要网络。定位、地图选点和拖动图钉保留同一张地图，保存 WGS84 坐标。两种底图均不可达时显示重试，GPS 和文字记录仍可保存。Leaflet 许可见 vendor/leaflet-1.9.4/LICENSE。

导航仅使用高德、百度原生 URI，传入对应坐标系的目的地，不提供网页路线或自动网页回退。微信可能拦截外部 App；唤起失败时会提示从微信菜单在浏览器打开。需要在微信内直接打开 App，须使用微信开放平台的开放标签并配置已绑定的移动应用和签名服务，网页端无法自行绕过微信拦截。腾讯原生路线接口需要开发者 Key，本项目尚未配置，因此不显示腾讯选项。厂区坐标不是实测门岗；浏览器模拟测试不代表实体手机 App 已开始导航。

直接用手机系统浏览器打开 HTTPS 链接，首次使用手机定位时允许网站访问位置，并开启手机的定位服务。新增点位流程：记录新场所 → 填写名称及地址 → 使用手机定位 → 在地图点击或拖动图钉微调 → 保存地址。浏览器模拟测试使用模拟 GPS 验证定位回调与保存，不能替代手机现场精度和实际 App 唤起验收。

走访流程：走访 → 选择场所 → 搜索并勾选已有场所 → 确认并返回走访 → 按顺序逐站导航、标记已到访。勾选只在确认后保存，取消或切换栏目会放弃本次选择；选择页不受首页搜索与筛选影响。“记录新场所”用于新增资料，与走访选择分开。缺少真实坐标的场所会显示“补充位置”，不会冒充可导航点位。已到访可以撤销或再次加入待走访；管理中可手动调整顺序、移出清单，清除已完成需确认且保留场所资料。当前不提供多站最优路线计算。

仅发布用户端资源，未包含管理端、测试或私人记录。
